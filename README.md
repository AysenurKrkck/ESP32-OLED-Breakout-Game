# ESP32-OLED-Breakout-Game
A retro Breakout arcade game built with ESP32 microcontroller, 1.3-inch SH1106 I2C OLED display, analog joystick, and passive buzzer.| ESP32 microdenetleyici, 1.3 inç SH1106 I2C OLED ekran, analog joystick ve pasif buzzer kullanılarak geliştirilmiş retro Breakout (Tuğla Kırma) oyunu.
